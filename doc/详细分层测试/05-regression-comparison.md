## 6. 结论

### ✅ 未劣化项
| 项目 | 结论 |
|------|------|
| Layer 2 核心链路 TPS | **-6%，在波动范围内** |
| MQ 发送成功率 | **100%，一致** |
| 阶梯加压膝点 | **Step 3 完全一致** |
| 无死锁/无连接泄漏 | **一致** |
| 时间轮 Local MQ TPS | **+32%，反而提升** |

### ⚠️ 受干扰项
| 项目 | 原因 |
|------|------|
| Layer 1 TPS -49% | 新测试未启用 `stress.mq.mock=true`，实际走真实 MQ |
| Burst TPS 差异 | 参数不同 (10组 vs 5组) |
| TW Mock 下降 15% | DB 中旧数据干扰 + GC 累计影响 |
| GC 次数偏高 | 连续跑 6 个场景，累计 GC |

### 🎯 核心结论

**主链路没有劣化**。Layer 2 持续 ~1,900 TPS，MQ 100% 成功，膝点一致。

新测试 Layer 1 偏低是因为 `application.properties` 中 `stress.mq.mock=false`，Mock 模式未生效。若需验证 Layer 1，需在 `application.properties` 中设置 `stress.mq.mock=true` 并重启。
